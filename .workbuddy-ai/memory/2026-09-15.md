# 2026-09-15

## Redesign da tela de overview do database (DatabaseOverview.tsx)

Rafael perguntou se fazia sentido manter a tela "home" do database e, em caso
positivo, deixá-la minimalista. Decisão: **manter** — ela é a `section` default
do `useConnectionTabsStore` (`SidebarSection = "overview"`, shortcut `1`), então
removê-la faria a conexão abrir sem estado inicial. Mas o conteúdo era um
dashboard, não um launchpad.

### Arquivo reescrito

`src/features/database/components/DatabaseOverview.tsx` (~700 → ~560 linhas).

O que foi removido / colapsado:

- **Seção "Server" inteira** → virou uma única linha de metadados (11px, muted)
  sob o nome: `● Connected · PostgreSQL 17.11 · neondb · UTF8 · GMT`.
- **Header com 4-5 badges** (PostgreSQL, Development, v17.11, require, LOCAL) →
  só `connection.tag` (env: Development/Prod) + `LOCAL`. O `ssl_mode` saiu da UI
  porque já está no connection string (`sslmode=` / `ssl=true`).
- **`StatCard` com borda + ícone** (causava o card "Size" órfão numa grid de 4
  colunas com 5 itens) → `Stat` sem chrome, dentro de um `flex flex-wrap`
  (`gap-x-8 gap-y-4`). Sem grid, sem órfão.
- **Duas `Progress` bars** (cache hit ratio, connection usage) → removidas.
  Agora só aparece um strip âmbar (`healthNotes`) quando algo é *notável*:
  cache hit < 95% ou uso de conexões ≥ 70%. Banco saudável não diz nada.
- **Labels `OVERVIEW` / `SERVER` / `SCHEMAS`** em uppercase + tracking → só um
  label "Schemas" em sentence case.
- **4 níveis de rótulo/badge duplicados** (versão no badge E no Server) → 1 fonte.

O que foi adicionado/melhorado:

- Regexes hoisted para o módulo (`HEX_COLOR_RE`, `SERVER_VERSION_RE`,
  `URL_PASSWORD_RE`) — resolve `lint/performance/useTopLevelRegex`.
- `COPY_FEEDBACK_LABELS` (Record) substitui o ternário aninhado do tooltip de
  copiar; `getLocalDbAction()` idem para o botão Start/Pause.
- `SchemaList` extraído como subcomponente.
- A tela agora usa o estado de copy do **parent** (`connectionString` +
  `copyConnectionStringFeedback` + `onCopyConnectionString`) em vez de manter
  state/ref/timeout próprios. Isso apagou ~50 linhas de `useState`/`useRef`/
  `useEffect` de feedback duplicado.

### Mudança de contrato (1 prop)

`DatabaseOverviewProps.onViewTables` mudou de `() => void` para
`(schema?: string) => void`. Antes, clicar numa linha da lista de schemas
chamava `changeSection("tables")` e **ignorava** qual schema foi clicado.
Agora o parent faz:

```tsx
onViewTables={(schema) => {
  if (schema) { changeSchema(schema); }
  changeSection("tables");
}}
```

em `src/routes/database/-DatabasePageContent.tsx:2000`. Único call site
(`grep onViewTables` → só ali).
